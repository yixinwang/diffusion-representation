\section{Finite-sample and approximation bounds}

\subsection{Active field oracle inequality}

Let $\cU_d$ be a bounded active-field class, and let $B_z=Q_z^\top V$.  Define the approximation error
\begin{equation}
 A_d^2=\inf_{u\in\cU_d}\E\norm{B_z-u(T,Z,C)}^2-\E\norm{B_z-u_d^*(T,Z,C)}^2,
\end{equation}
where $u_d^*=\E[B_z\mid T,Z,C]$ is unrestricted.  For empirical risk minimization $\wh u_d$ under bounded squared loss, a standard Rademacher argument gives, with probability at least $1-\alpha$,
\begin{equation}
 \E\norm{\wh u_d-u_d^*}^2
 \lesssim A_d^2+\mathfrak R_n(\ell\circ\cU_d)+B^2\sqrt{\frac{\log(1/\alpha)}{n}}.
 \label{eq:oracle}
\end{equation}
The scientific content is not the generic empirical-process inequality; it is that $A_d$ is the observable closure boundary.  If $A_d$ remains large, the claimed quotient is false at that dimension.

\subsection{Endpoint perturbation}

Let $Y_t=(Z_t,R_t)$ follow the exact structured coordinate field $a_t^*$ and let $\wh Y_t$ follow $\wh a_t$.  Suppose both use the same source, $a_t^*$ is $L$-Lipschitz, and
\begin{equation}
 \int_0^1\E\norm{\wh a_t(Y_t)-a_t^*(Y_t)}^2dt\le\varepsilon^2.
 \label{eq:field-error}
\end{equation}

\begin{proposition}[Wasserstein stability]
Under the preceding assumptions and exact integration,
\begin{equation}
 W_2(\cL(\wh X_1),\cL(X_1))
 \le e^L\varepsilon,
 \label{eq:w2}
\end{equation}
where $X=QY$.
\end{proposition}
\begin{proof}
Couple the solutions through the same source and write $\Delta_t=\wh Y_t-Y_t$.  Add and subtract $\wh a_t(Y_t)$, apply the Lipschitz inequality and Gr\"onwall, then Cauchy--Schwarz in time.  Orthogonality preserves Euclidean distance, and the coupling upper bounds $W_2$.
\end{proof}
A more realistic off-path bound needs regularity of $\wh a_t$ or a change-of-measure control.  Equation \eqref{eq:w2} is stated only for the true-path error in \eqref{eq:field-error}.

\subsection{Dimension and block selection}

Let $\wh R_d$ be held-out active-plus-fiber loss, let $\operatorname{pen}_n(d,b)$ be a capacity penalty, and let $\operatorname{cost}(d,b)$ include measured FLOPs or time.  Select
\begin{equation}
 (\wh d,\wh b)=\argmin_{d,b}
 \left\{\wh R_d(b)+\operatorname{pen}_n(d,b)+\lambda\operatorname{cost}(d,b)\right\}.
 \label{eq:model-select}
\end{equation}
A finite candidate-set union bound yields an oracle inequality against the best candidate up to twice the uniform validation deviation.  This formalizes the bias--variance--compute tradeoff; it does not manufacture a low-dimensional quotient when no candidate has small held-out defect.

\section{Experimental protocol}

\subsection{Fairness and leakage controls}

Every seed is split before fitting.  Standardization, chart estimation, residual matching, early stopping, VAE/RAE encoders, decoders, linear-probe tuning, and evaluator selection use only train and validation data.  Test data are used once for final metrics.  All generative methods receive the same examples, labels, active dimension, sample count, and Heun NFE.  FIQ, VAE-LFM, and RAE-LFM use the same active vector-field architecture.  The full ambient width is chosen so its trainable generation parameters do not exceed the FIQ generation budget.  Endpoint decoder/fiber and chart time are included.

The five registered distribution metrics are sliced $W_2$, unbiased Gaussian-kernel MMD squared, energy distance, covariance error, and normalized mean error.  Digits additionally use a train-only feature/classifier network to report feature Fr\'echet, class-conditional feature Fr\'echet, feature-space precision/recall, and requested-label accuracy.  Reports retain all five seeds and use paired bootstrap intervals; a lower mean is not promoted when its interval includes zero.

The target has $D=18$, $d=2$, a nonlinear active diffeomorphism, and eight conditionally correlated $2\times2$ Gaussian residual blocks, hidden by a random orthogonal chart.  Each seed uses 5,000 train, 1,500 validation, and 2,500 test examples.  The baselines are:
\begin{enumerate}[leftmargin=*]
\item GF-FIQ with block fiber;
\item the same model with diagonal fiber;
\item a parameter-matched full ambient flow;
\item KL-VAE latent flow with diagonal stochastic decoder;

\section{Failure trace and adversarial audit}

\begin{enumerate}[leftmargin=*]
\item \textbf{Initial failure:} active eigenspace recovery succeeded, but arbitrary residual rotations destroyed local fiber blocks.  This falsified the claim that active recovery alone was sufficient.
\item \textbf{Repair:} the conditional-covariance graph and cross-fitted gauge matching restored the exact pair structure without test data.  The likelihood gain then matched theory.
\item \textbf{Support check:} every deterministic $d<D$ proposal was rejected for full-density parity.
\item \textbf{Compute check:} the chart and fiber are included in timing.  The dense chart prevents an image-scale asymptotic claim.
\item \textbf{Baseline check:} removing the VAE KL penalty and giving the RAE a block stochastic decoder produces a materially stronger baseline; it is retained.
\item \textbf{Metric check:} digits feature Fr\'echet is not declared significantly better when the paired interval includes zero.
\item \textbf{Information check:} the same labels and splits are supplied to every method; no group or test labels enter model selection.
\item \textbf{Proof boundary:} exact pair matching is proved; greedy blocks of size four on digits are not.
\end{enumerate}
The detailed registry and audit are stored with the code in \texttt{theory/approach\_registry.md} and \texttt{theory/adversarial\_audit.md}.

\section{What is and is not established}

\paragraph{Established.}
On $\mathfrak T(d,b)$, the algorithm has exact full-dimensional endpoint law under realizability and exact integration, exact latent/fiber KL decomposition, and iterative dynamics only in dimension $d$.  Raw flow labels recover the active subspace in the spiked linear-Gaussian regime.  Pair blocks are identifiable under a matching margin.  A diagonal stochastic VAE decoder has the explicit strict gap \eqref{eq:diag-gap}.  The synthetic experiment verifies all of these mechanisms.  The digits experiment establishes improvements in held-out sliced Wasserstein and requested-label accuracy over the implemented latent baselines.

\paragraph{Not established.}
There is no universal cheap quotient, no universal dominance over an unrestricted VAE, no proof that the greedy block-four grouping is optimal, and no demonstrated parity with a converged full pixel flow on modern image benchmarks.  A structured reversible image chart, convolutional or tokenized block fiber, compute-matched DiT baselines, and image-scale FID/likelihood experiments are required for that next claim.

\section{Conclusion}

The mathematically coherent route is not to compress the endpoint and hope that a low-dimensional code happens to be generatively sufficient.  It is to identify a quotient of the full generative law, preserve complementary randomness, and spend iterative computation only where the transport is genuinely nonlinear.  The residual gauge is part of the problem: a correct active subspace can still yield an inefficient fiber in the wrong basis.  Once the gauge is learned from conditional dependence, a block-local stochastic fiber gives exact full-density parity on a nontrivial class and a measurable strict separation from diagonal VAE decoders.  The current evidence justifies this restricted theorem and algorithm.  It does not yet justify an image-scale universal claim, which is now reduced to explicit, testable obligations: structured chart cost, small held-out quotient defect, cheap fiber complexity, and compute-matched full-flow quality.

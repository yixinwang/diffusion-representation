# Exact source-fit global-context derivation

Let `g in R^8` be the already available global/coarse projection, and let `mu,v` be the final eight entries of the frozen source-fit R13 mean and state vector. Order coordinates by decreasing `|v_j|`, orient them by `sign(v_j)`, and define

\[
q=DP(g-\mu),\qquad g=\mu+P^T Dq.
\]

`DP` is orthogonal, reversible, and has `log|det|=0`. R15 uses `c=q_1:4` only as the statistic conditioning the unchanged R14 target map; all eight global coordinates and every visible coordinate remain retained.

For target `t=r u in R^4` and unchanged state `s`,

\[
a_s(c)=0.72\frac{A_s(c/\|c\|)}{\sqrt{1+\|A_s(c/\|c\|)\|^2}},
\]

\[
M_a(u)=\frac{(1-\|a\|^2)u+2(1+a^T u)a}{1+\|a\|^2+2a^T u},
\qquad t'=rM_{a_s(c)}(u).
\]

The conditioner and state are unchanged, so the inverse uses `M_{-a}`. The exact added target log-Jacobian is

\[
3[\log(1-\|a\|^2)-\log\{1+\|a\|^2+2a^T u\}].
\]

The complete flow Jacobian is block triangular. Zero matrices recover the exact parent, and the standard-Gaussian change-of-variables likelihood remains normalized.

For an aligned teacher whose target conditional law is generated by the inverse map from source-identifiable global context, the parent using an independent fine statistic has log-score gap

\[
D^{-1}E\,KL\{P(T\mid C_g,S)\|Q(T\mid S)\}>0.
\]

Strict propriety gives an energy-score gap `0.5 E(P,Q)>0` for distinct finite-first-moment laws. The experiment verified a large NLL and dependence gap, but its proper-energy lower interval was below the preregistered practical margin.

First transfer failures: source context is not identified; dependence lies outside the selected four global coordinates; one Möbius map cannot express the conditional law; held-out risk is below the fixed BIC charge; or a state lacks the fixed minimum support.

# Continuous observed-pair flow prototype

This is a new declared pair-density family. It replaces the cosine feature in Pro11 with a fixed continuous trapezoid feature, permitting a direct quadratic inverse. It does not claim to reproduce the cosine law. The proposed continuous model is explicitly constructed with `Learner.fit(observed, continuous_context=True)`; the default binned learner remains a documented ablation and generally has a discontinuous joint map.

The public feature has knots [0,1/8,3/8,5/8,7/8,1], values sqrt(3/2) times [1,1,-1,-1,1,1], zero mean and third moment, and unit second moment. Pair density is 1+theta(C1) psi(u) psi(v). At |theta|<=0.45 its density is between0.325 and1.675. The conditional CDF integrates a linear feature on each of five pieces, and its inverse uses four knot comparisons and one stable quadratic formula, with algebraically equivalent affine endpoint formulas. All Gaussian coordinates are retained. There is no scalar root-search loop or grid approximation term in the ideal map.

Each block's unknown matching is learned from the first half of observed arrays; a whole block falls back to a product density unless thresholded degrees all equal one. Separate whole arrays estimate four nonlinear context functions, with each array's360 pair products pooled as one response per block. The continuous variant linearly interpolates the32 fitted bin values at bin centers and extends constantly at the endpoints. It adds no teacher information or fitting stage. The constant-context model is an ablation with the same observation-only interface.

Under the precisely stated aligned root-histogram, Lipschitz, sharing, detectable-matching and sample-split assumptions, the continuous variant has the symbolic expected joint-KL bound whose ordinary numerical evaluation is0.6528593887 at4,000 independent3,072-dimensional fitting arrays. The fixed-chart conditional scalar-product floor is88.2. The adjacent `pro13_continuous_context_audit.md` derives this bound. The binned variant's smaller0.4332742770 bound remains separate. These decimals have not been interval-certified.

The continuous model is a full-dimensional homeomorphism on the open cube with piecewiseC1 structure and an a.e. Jacobian. It is not globally C1: the feature, root histogram quantile and coefficient interpolation have derivative corners. Learned coefficient slopes may reach28.8; the assumption L=0.5 applies to the true function, not to the fitted interpolant. Ordinary covariance, Gaussianized covariance and raw squared-error masked means miss this dependence, while the declared nonlinear observed feature detects it. No semantic latent identification or VAE representation superiority follows.

No full-size fit, PSC experiment, native image or video run has been performed with this prototype. Six learner tests and ten scalar tests passed, including a small observed unknown-matching fit, nonconstant-context dense Jacobian, source roundtrip, continuity, state serialization, fallback, empty bins and numerical saturation rejection. Sampling calls no RNG and rejects saturated Gaussian CDF values without clipping or replacing sources. Its floating arrays approximate the ideal continuous model; no continuous-truth KL against an atomic floating output law is asserted.

An independent sweep found a real cancellation defect in the initial scalar endpoint implementation despite its initial tests. The original source and failing report are retained. Exact endpoint identities corrected it; the expanded2,136,240-case sweep then passed with no output clipping, maximum CDF roundtrip error1.11e-16 and agreement with the independent inverse within3.33e-16. See the retained independent final review and source hashes.

Run the16 focused tests from this directory with `python -m pytest -q test_reference.py test_learner.py`. The independent diagnostic scripts reproduce their neighboring JSON files and some import a sibling mathematical checker; copy the complete research layout into a new scratch directory before rerunning them. Do not overwrite the preserved historical failure or result records. The production learner imports only the scalar reference and NumPy/SciPy, not those diagnostic scripts.

Graph discovery still uses dense Gram matrices: approximately4.1472 billion scalar multiplications for the declared setting. The direct inverse alone does not establish lower total training or inference cost than a strong latent model. A same-information analytic pair control can implement this exact model and tie it. A future experiment must charge discovery, root learning, interpolation, all setup and memory, include stronger globally interacting FM and the analytic-copy tie, and retain the zero-mean-signal failure. No broad quality or efficiency superiority is claimed here.

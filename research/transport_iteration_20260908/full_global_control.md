# Full-dimensional globally attending control

The additive `GlobalFullFlowMatching` control retains all 3,072 RGB coordinates. A fixed pixel permutation packs each 32-by-32 array into 48 channels on an 8-by-8 grid. The same global attention field used by the residual comparator then sees all 64 spatial tokens. It receives one constant-zero context channel to satisfy the existing network interface. This channel supplies no data; its 1,116 input weights are included in the total of 264,912 parameters at width 124.

The ordinary and Gaussian-reference probability paths use this identical network. Both start from the entire standard Gaussian source and integrate with Heun, using two velocity evaluations per step. There is no learned analysis or decoder to train for this control. A future comparison must give its fitting stage the complete standalone budget charged to the candidate. Packing costs linear work in the observation dimension; global attention costs quadratic work in the number of tokens. Neither path has a supplied exact finite-step likelihood.

Five fabricated tests check the exact permutation and Jacobian, complete source preservation with a zero field, both training objectives, dependence between distant tokens, and parameter counts. These are software checks, with no native-image fitting or quality result. This is a stronger baseline assembled from existing flow matching, global attention and lossless packing, with no publication-novelty claim. The Gaussian-reference derivation and its relation to conditional flow matching are recorded separately.

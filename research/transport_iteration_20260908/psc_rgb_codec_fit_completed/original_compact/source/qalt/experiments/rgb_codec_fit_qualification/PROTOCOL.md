# Prospective FIT-only RGB codec qualification

Prospectively frozen before real-image fitting; no job has run at source preparation. One future V10032 run uses seed79201, the frozen canonical4000 FIT images, and a fresh default RGBCodecFlowMatching codec. The untrained latent field remains registered/resident and is disclosed in total initialization/memory. No synthetic checkpoint is reused. No latent FM, candidate generator, FID/KID or held-out metric is trained/evaluated here. The intended output is a new exclusive path under mth260022p, with a one-hour allocation as an outer runtime cap; research/engineering cost is retained.

The unchanged strict observed_flow_data loader deserializes the five eligible official training batches and physically constructs the selected1000 repair array. The runner never accesses that repair array, its model statistics or evaluation. It uses only returned FIT images/IDs and ledger, then discards the loader object. Previously excluded discovery/protected/test samples do not enter model work; official test is not read. Label handling remains solely the frozen loader's stratified selection. FIT[0,1] is rounded tofloat32 then mapped to[-1,1]. Evaluation targets are the same rounded model inputs mapped back to[0,1]. Inputfloat64 and ordered ID hashes are saved.

AdamW uses only codec parameters, batch32, LR2e-4, betas(.9,.99), decay1e-4 and the existing L1+.2(1−SSIM)+1e-4latentL2 loss. No gradient clipping. The wall schedule warms linearly from2e-5 to2e-4 during the first30 seconds (5%), then cosine-decays to2e-5 at600 seconds. NumPyPCG64 seed79202 supplies replacement FIT minibatches. CPU/CUDA Torch initialization uses79201. Every drawn subset index, canonical FIT ID, actual LR and draw/completion wall time is journaled. Loss and all intended gradients/updated codec parameters must be finite and present; failure is terminal.

The600-second fitting clock starts after optimizer construction and includes initial checkpoint, updates, synchronization, checkpoint/hash work and progress/step I/O. Standalone wall time also includes source/preflight, loader, initialization, optimizer construction, normalization/cache and reconstruction evaluation. Save initial plus nominal60/150/300/450/600-second checkpoints; each records actual completed updates, elapsed time, model/Adam and all RNG states. Crossed thresholds capture the latest completed state; a single slow update/I/O can cross multiple thresholds, which are reported without inventing extra updates. No new update starts at/after600seconds. A final single update and required serialization may overrun; no retry or extension. Zero updates fail.

Final weights and checkpoint hash are frozen before any reconstruction evaluation. Normalization is FIT-only, streaming over all4000 encoded examples, then freezes per-channel population moments. All16 standard deviations must be finite and>=.001; degenerate normalization fails terminally. The current implementation executes two encoder passes per normalization chunk: one through the existing moments API and one to assemble the cache. Both are charged. Save the float32 normalized4000×16×8×8 cache (16,384,000 payload bytes), means/std and normalized state. No independent-site statistical claim is made from spatial pooling.

Only then reconstruct FIT images and save allfloat32 reconstructed RGB, per-image MSE/SSIM and the first16 target/prediction arrays. Metrics use[0,1] RGB without clipping. SSIM uses the existing valid11×11 Gaussian sigma1.5 population-moment formula, constants.01²/.03²; evaluation arithmetic isfloat64 to reduce aggregation error. Global PSNR is−10log10(mean of all pixel errors), not mean per-image PSNR. Gates are globalFITPSNR>=26, meanFITSSIM>=.85 and all16 latentstd>=.001 finite. Zero MSE is represented as infinitePSNR in the report. These are engineering reconstruction floors on training data, not generalization, generative fidelity, a competent latent generator, SOTA or candidate superiority. Failures remain results; gates are never relaxed after viewing images.

Source closure binds the unchanged codec module, __init__, core, data_integrity, observed_flow_data, observed_manifest, this runner/protocol/launcher and focused test to an exact Git HEAD and copies all bytes. No alternate loader or source fallback exists. Fresh output/no overwrite, signals/failure checkpoint/state, progress journals and complete payload hashes preserve partial runs. Source and allocation preparation are part of the already authorized research scope.

Full roundedfloat32 FIT evaluation targets are retained locally and on PSC with their payload hash to support complete independent MSE/SSIM replay. A later Git publication may explicitly omit those raw targets with exact size/hash/retention location; it must not imply that omission is a complete data payload. Optimizer construction seconds, full/codec/field counts, untrained-field status and allocated/reserved GPU peaks are reported. Both the ten component tests and four qualification tests run before canonical loading under an explicit frozen PYTHONPATH, with both test files in source closure.

The final fitting elapsed/overrun clock closes after hashing fit_frozen.pt. FIT_FROZEN and fit_accounting receipt serialization is excluded from that stage boundary and included in standalone wall time, avoiding recursively timing the receipt that contains its own duration. Final overall GPU memory peaks are explicitly named since_fit_reset; they do not claim to cover initialization before that reset.

## Reproduction

Run in a copy of this directory so result rewrites cannot alter the original inspection package. The fitting scripts use NumPy/SciPy and no network, credentials, GPU, repository or scheduler.

```sh
sha256sum --check SHA256SUMS
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python run_checks.py --math
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python run_checks.py --seed 1109101
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python run_checks.py --seed 1109102
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python run_checks.py --seed 1109103
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python audit_saved.py
```

The saved-state audit can also run directly without the fitting commands. Mathematical libraries/platforms can change regenerated floating-point bytes; report those discrepancies rather than silently substituting numerical closeness for exact hashes. Full4000x3072 fitting/source arrays are regenerable from the recorded code/seeds but are not bundled. Their exact hashes, shapes and dtypes are in the seed JSON files. Generated64-row verification banks are bundled.

Recorded per-stage CPU fitting intervals are single diagnostics, not all-in timings or comparisons to FM. Training-fixture generation alone took substantially longer than fitting. No efficiency claim is inferred from those numbers.

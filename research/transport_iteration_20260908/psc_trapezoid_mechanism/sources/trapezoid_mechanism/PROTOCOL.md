# Six-cell observed-pair mechanism validation

This is a prospective synthetic mechanism experiment, not a latent diffusion comparison or an image/video benchmark. The public dimension is 3,072, with 192 roots and four blocks of 720 residuals. The continuous trapezoid-pair learner was published at adcb87c. Its interpolation, direct inverse, dense graph statistic and clipping bounds remain unchanged. Packed-sign discovery is not part of this run.

Three fresh fixture seeds are 13109101, 13109102 and 13109103. Each is evaluated under the positive and zero-mean worlds. Roots have unknown eight-bin histograms: normalize independent Uniform(0.5,1.5) positive weights, then mix half with the uniform histogram. This ensures all root densities exceed 0.5. The fixture explicitly makes the first root uniform. Every group has an unknown random perfect matching and parameter sign times [offset + 0.075 sin(2 pi C1 + phase)]. Offset is 0.35 or zero. The positive law meets the stated mean-signal and Lipschitz assumptions; the zero-mean world violates the discovery signal while retaining conditional dependence. The same source bank and fixture parameters are used across the two worlds of a seed, changing only the offset. These are paired worlds, not six independent fixtures.

Exactly 4,000 independent full-dimensional Gaussian vectors generate each observed fitting bank. Their seed is fixture seed + 10,000,000. The source and observed banks are saved in full before fitting. Truth, source correspondences and graph are not arguments to any fit API. All estimators receive the same observed bank and public feature, grouping, root bins, context coordinate, and parameter bounds. Numerical source/output saturation fails explicitly without replacement. The ideal-law finite-learning theorem is separate from these ordinary floating realizations.

Independently fit continuous-context, binned-context and constant-context learners from each observation bank. Each pays its own validation, dense graph, root estimation, function estimation and serialization costs. The product ablation only estimates its root histograms, without wasted graph work. Repeated method fits use the same observed information and deterministic estimator, not independent statistical replicates. Every fit in every cell completes before any population-risk evaluation or graph-recovery assessment. Save fitted states and graph degrees/fallbacks. There is no repair-based selection, hyperparameter sweep, or protected dataset in this experiment.

This is a one-pass analytic-estimator comparison, not a nominal 600-second neural-training budget. Report actual wall and CPU time, shared fixture/data-generation cost, separate evaluation time, and process peak memory. Common source/data reading and validation are identified; do not convert unused time into a claim against an unrun neural method. No optimized latency frontier is measured. The single batch-64 sample duration is diagnostic only, with no warmup/randomized timing repetitions.

The independent population evaluator uses exact feature-moment series in ordinary float64 and context Gauss-Legendre integration split at all root and estimator boundaries. For Z=psi(U)psi(V) under independent uniforms, E Z^(2k)=(3/2)^(2k)[(k+1)/(2k+1)]^2. It evaluates true entropy and cross entropy, including true/fitted edge overlap. A false fitted edge has independent uniform endpoints conditional on the root, so its expected log density uses the product marginal. Root KL is categorical. Evaluate 128 series terms and compare context orders 32 and 64. This is numerical population evaluation with convergence checks, not certified interval quadrature or empirical test-set risk.

For each cell, save a common 64 by 3,072 Gaussian bank from seed + 30,000,000 and all four generated banks, forward determinants, reconstructed sources, inverse determinants and log densities. This bank validates numerical behavior; it is too small for a generative-quality comparison and is not used to estimate one. The exact copied-state wrapper must agree bitwise on every saved output/density. Its inherited fitting cost is the candidate's full fitting cost. It is an equality control, never a beatable baseline.

Numerical gates are maximum source roundtrip <= 1e-9, determinant cancellation <= 1e-8, and population quadrature difference <= 1e-8. Failures preserve source/output arrays and phase records and stop without rerunning or replacing the cell. Graph fallback in the zero-mean world is an expected scientific negative, not an execution failure. The expected-training-risk bound is not used as a per-fit pass criterion. Publish all seeds, worlds, methods and failures.

The source closure includes the complete experiment and published scalar/learner sources, verified against the frozen commit and copied before import. Output creation is exclusive. Hash and retain all payloads, including approximately 1.2 GB of full fitting observations and generating sources across six cells. PSC execution uses a single RM-shared allocation, four CPU cores, 8 GB memory, and a 20-minute limit, with numerical-library threads fixed to four. Environment versions and source hashes are recorded. No method is run on a different node for a claimed paired speed result.

The next comparative study still requires independent analytic MLE and strong learned global flow-matching baselines with matched prior, public information, compute and proper output scores. Success here would establish an implemented dependence-learning mechanism in its declared class. It would not establish native quality, efficiency over latent diffusion, semantic representation, or superiority to an exact-copy decoder.

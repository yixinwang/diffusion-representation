# Observed-only learner prototype

`learner.py` fits only finite open-unit observed arrays. Its public default dimension is 192+4×720=3072. No graph, coefficient, simulator label, held-out array, or truth parameter is accepted by `fit`.

Each root coordinate receives its own eight-bin Laplace-smoothed histogram from all N arrays. The first floor(N/2) arrays produce each block's uncentered feature Gram matrix. An absolute off-diagonal value strictly above 0.175 creates an edge. The entire block is accepted only when every vertex has degree exactly one; otherwise that block has no pair factors, zero coefficients, and a retained failure flag. A rejected graph is not silently repaired using the regression half.

For each accepted block, the second half produces one regression response per array: the mean of all pair feature products within the block. Those responses are averaged within 32 bins of the observed first root coordinate C1. Empty bins receive zero; estimates are projected to [-0.45,0.45]. The constant-context ablation uses the same observations, split, matching rule and root estimator, replacing C1 bins by one mean. Pair products are never counted as independent arrays. Root fitting and graph fitting share some observations by the declared algorithm; there is no claim of independence between those fitted components.

Generation applies Phi to every Gaussian source coordinate, inverts root histograms, obtains context from the generated first root coordinate, and applies each pair inverse to its original coordinate indices. It adds no noise and retains every residual source, including all product-fallback coordinates. Encoding reverses this map. `log_prob` returns the joint unit-cube density a.e.; Gaussian encode/decode include the full base-density Jacobian. Histograms, the context-bin rule, and feature corners make the joint map only piecewise differentiable. The public scalar CDF property does not confer global C1 smoothness on this learned joint map.

All computation is float64. Inputs and outputs must remain strictly inside the unit cube. Phi saturation, inverse output endpoints, and nonfinite values cause explicit rejection, with no source truncation, clipping, or resampling. Coefficient projection is a specified estimator operation and is distinct from numerical repair. Root cumulative endpoints are set to their algebraic value one; finite-arithmetic cumulative sums and roundtrip tolerances are not exact arithmetic claims. Gaussian outputs and generated arrays are finite numerical approximations; the reported density is the corresponding ideal-law formula, not continuous KL of atomic floating outputs.

The diagnostics retain dense Gram multiplication/addition counts, root scalar bin updates, pair-product counts, array counts, context occupancies and graph degrees. For N=4000 and the public dimensions, dense graph fitting requires 4×2000×720²=4,147,200,000 scalar multiplications under the ordinary dot-product count. This is not a BLAS instruction count or a runtime measurement. Feature construction, thresholding, allocation, histogram work and serialization remain additional costs. No such full-size fit was run.

Four fabricated tests passed. They include a nonidentity three-dimensional dense finite-difference Jacobian and full-source Gaussian roundtrip, exact state serialization, a 2048×5 observed-data unknown-matching fit, manually checked regression mean and root counts, full-block fallback for invalid degree, empty-bin behavior, strict tail rejection and an RNG-disabled sampling check. The initial regression-mean test used exact floating equality across different summation orders; it was corrected to an explicit 2e-15 absolute tolerance. No production model, real data, PSC job or reference source was changed.

The current coefficient histogram is piecewise constant in C1. When adjacent fitted coefficients differ, its conditional inverse generally jumps across that context boundary, so the full joint map is discontinuous there. A.e. invertibility/density remains the claim; it is not a continuous joint transport. The opt-in continuous interpolation variant below is implemented separately from this preserved default.


## Opt-in continuous context variant

`Learner.fit(..., continuous_context=True)` uses exactly the same fitted clipped bin coefficients and all original fitting diagnostics. Only evaluation changes: linearly interpolate coefficients at centers (j+0.5)/K and extend the endpoint coefficients constantly. The default flag is false; loading an older state without the flag retains binned behavior. `constant_context=True` remains a one-coefficient ablation and is unaffected if the continuous flag is also supplied. Both flags are serialized explicitly.

In ideal arithmetic the interpolated coefficients are continuous and stay within the fitted interval. The positive root histogram CDF/inverse, continuous pair CDF with transformed-coordinate derivative at least 0.325, and continuous parameter interpolation yield a homeomorphism between the full open cubes, or between Gaussian input and the open output cube. The map is piecewise C1, with a.e. density/Jacobian identities; it is not globally C1 at histogram, feature, or interpolation corners. The learned coefficient slope can reach 2*kappa*K=28.8 under the public configuration. This is not the assumed true-function Lipschitz bound 0.5, nor a conditioning or numerical-stability guarantee. Strict numerical endpoint rejection remains unchanged.

The independent symbolic analysis in `work/pro13_continuous_context_audit.md` applies to this evaluation variant under its stated assumptions; its bound is distinct from the default binned theorem. Two additional fabricated tests verify continuity across the former context-bin boundaries, a nonzero context derivative and dense Jacobian, full Gaussian-source roundtrip, endpoint extension, serialization/backward compatibility, identical fitted coefficients and retained constant-context behavior. All six learner tests pass. No additional observations, full-size fits, or timing experiments were used.

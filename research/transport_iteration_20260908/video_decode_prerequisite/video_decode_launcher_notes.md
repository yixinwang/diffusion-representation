# External first-clip launcher: prepared, not run

`launch_video_decode_guarded.py` verifies a full expected Git HEAD, a clean supplied checkout, and exact frozen Git bytes for runner, helper, bounded reader and the preserved extraction manifest. It checks all264 dependency entries, including sizes and SHA256, under the fixed isolated `dependencies-attempt3` directory. Unexpected non-cache files fail. Existing bytecode caches are bypassed with an exclusively new pycache prefix and bytecode writes disabled. The imported stack is selected through isolated PYTHONPATH and user-site suppression. The wrapper independently checks PyAV16.1.0, Pillow12.1.0 and NumPy2.2.6 before archive access.

Supply a separately prepared new detached checkout of the root-provided frozen commit, the verified header-manifest path, and a never-used output directory. The launcher does not create/check out revisions or submit jobs. Its output parent is acquired exclusively; it saves source bytes and status before the single subprocess call, preserves stdout/stderr and failure traces, and never retries. The wrapper gets its own new `decode` child directory. A900-second subprocess cap and20-minute Slurm cap bound the operation. A launcher timeout, interrupted transport or unknown scheduler outcome is not permission to resubmit; inspect the existing attempt.

`video_decode_first_clip.slurm` is a draft2CPU/4000M/RM-shared20-minute script using accountcis260243p. Its launcher path is a proposed external staging path and must be copied/verified before an authorized submission. No commit ID or final remote output has been selected here. Root must provide the frozen revision and authorize execution first. Only syntax compilation and shell syntax checking were performed; no remote action or decode occurred.

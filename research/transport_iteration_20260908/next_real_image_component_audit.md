## What blocks a competent conventional latent baseline

1. **No ready unconditional RGB codec/prior pipeline in qalt.** The learned analysis optimizes exact full-coordinate Gaussianization and has no information-discarding bottleneck, decoder reconstruction/perceptual objective, posterior parameterization, learned latent normalization, or standalone reconstruction-quality checkpoint. Its residual model still evolves2880 coordinates. Calling this ordinary compressed latent diffusion would misstate both the model and its cost.

2. **The historical autoencoder example is a different task.** `src/unsupervised-cocycle/cocycle_fm_mnist.py:229,244,426` has784-dimensional MLP encoder/decoder training, but the latent field`:281` takes both observed endpoint codes. Training`:452` interpolates encoded image pairs; generation/evaluation`:500` encodes both source and target. It is supervised-by-endpoints translation, not unconditional sampling from a Gaussian latent prior. Do not reuse its reported image metrics or run its loader/evaluator for this task. Components would require a new RGB codec and unconditional prior, not just changing the input shape.

3. **A stronger field architecture needs deliberate integration.** Current global FM is one attention block, shallow convs and a scalar time channel; it lacks a multiscale residual U-Net/transformer stack and richer continuous time embedding. `src/unet.py:122` is not a drop-in replacement: its time embedding is discrete integer lookup, it uses BatchNorm extensively, defaults differ in output channels, and it has no conditional packed-latent interface. It would need a separately tested continuous-time adapter and explicit train/eval normalization behavior. No source here proves that adding any named architecture alone yields competence; fit-only learning/validation curves and sufficient optimization remain necessary.

4. **Codec information and cost are not yet registered.** A from-scratch codec needs a declared latent shape/compression ratio, training objective, fixed normalization, deterministic/stochastic posterior and decoder policy, and a reconstruction diagnostic on permitted fitting-validation data. Charge codec construction/training, fitting encodes/cache/storage, latent prior fitting, any perceptual-network use during codec training, and full decoding. A pretrained codec would require authenticated source/weights/training-data provenance and a separate pretrained-information comparison; it cannot silently enter only one arm under the present equal-information regime.

5. **Standard compressed generation and full active source dimension are distinct restrictions.** A conventional deterministic codec decoder driven by a d-dimensional latent uses d Gaussian coordinates, not3072 active coordinates. Padding its source with ignored noise does not make it a full-dimensional density. Conversely, forcing a2880-coordinate stochastic decoder onto every conventional latent baseline changes its cost/class and can deliberately handicap it. The present allD stochastic comparison is coherent, but cannot be advertised as a complete conventional latent-diffusion benchmark. Any additional compressed baseline must disclose actual used source dimension, common standard-normal convention, and lack of an ambient exact density where applicable.

## Minimal next implementation requirements

For an immediate **small allD development lane**, no new codec is necessary. Add a separate source-frozen orchestrator around the existing global full FM and independently trained LearnedLatentFlowMatching, using the strict observed loader and pinned evaluator. Preserve candidate/analysis-only controls, but distinguish a shared-A ablation from independent complete-pipeline training. The currently instantiated learned-latent class fixes both FM widths to analysis width; allow explicit coarse/residual field configuration or use a clearly recorded composed factory as run_shared does, with strict reload/count checks. Separate coarse/residual actual NFEs; the current composite `steps` applies to both, so total field calls are4*steps, not2*steps. Hierarchical cost is2*steps*(levels+1); ambient global is2*steps. Report sampler latency directly rather than treating these unlike calls as interchangeable work.

Use the newer aggregate finite-step semantics for this new runner. Old `run_shared.py:119` ignores None gradients and synchronizes per parameter, and `heun_integrate:53` checks shapes but does not itself reject every nonfinite intermediate. The new common wrapper must require all intended gradients, reject nonfinite field/output/logits before sigmoid, preserve failing states, and report the cost of validation. Invertibility/LD tests belong to the exact analysis/candidate, not a demand that generic finite-Heun FM expose an exact inverse/NLL. No FM training loss or analysis likelihood may be labelled full-model density.

Close the timing envelope explicitly: common input preparation/source validation, model initialization, optimizer and fit, analysis/codec encoding and cache, transfers/offload/checkpoints, final generation plus inverse chart/codec, and evaluation/feature extraction must be recorded. Identify resident shared input/cache/model memory versus incremental allocations, peak CPU RSS versus GPU allocated/reserved bytes, batch1 latency versus batched throughput, actual warmup/compilation costs, update overruns/exposures, and every tuning trial. Parameter-matching is a secondary inventory, not the fairness criterion. Existing three-repeat latency is a smoke statistic, not a decisive efficiency frontier.

For a **conventional codec lane**, implement and qualify the codec/unconditional prior/interface described above before interpreting any comparison as competent latent FM. Permit baseline-specific fitting-budget allocation and an explicitly bounded fit-only tuning procedure rather than blindly reusing90/90/180 seconds. Report all NFE/compute points and outcomes; do not select a winning checkpoint/path using recycled repair. A tiny4000-image study can establish only development behavior of its specified models. Current code/receipts supply no real-video baseline or VAE representation guarantee.

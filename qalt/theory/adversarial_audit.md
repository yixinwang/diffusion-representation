# Adversarial audit

## Closed universal claims

An unrestricted latent flow/diffusion class contains QALT. If the baseline receives the same analytic fiber, it can use the exact exponential update and tie QALT in quality. If it receives the same sharing groups, it can pool the same samples and tie QALT's finite-sample risk. A reversible chart applied after a fixed VAE does not add information because it preserves the sigma-field generated by the VAE code.

## Surviving claims

For a common realized active sampler, an inexact finite-step fiber creates an additive positive Gaussian KL and Wasserstein term that an exact endpoint map removes. QALT is strictly cheaper when measured saved repeated-token cost exceeds all chart, packing, path, fiber, and decoder overhead. Correct pooling reduces estimation risk only relative to a comparator that estimates the coordinates separately.

## Missing bridges

- learned-chart recovery under a bounded-cost chart class;
- post-selection closure and fiber error bounds;
- nonlinear score/SDE change of variables;
- a full end-to-end GPU cost theorem;
- a realistic image/video study against sparse attention, token pruning/merging, few-step solvers, and exact affine-fiber controls.
